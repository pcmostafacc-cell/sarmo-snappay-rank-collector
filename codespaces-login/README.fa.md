# ورود دستی اسنپ‌پی در GitHub Codespaces

این پیکربندی Codespace را فقط برای ورود موقت باز می‌کند. مرورگر داخل پورت خصوصی GitHub اجرا می‌شود، ورود و کد در خود صفحهٔ اسنپ‌پی انجام می‌شود و یک مجوز کوتاه‌مدت وردپرس انتقال رمزگذاری‌شدهٔ نشست را ممکن می‌کند. پایش روی GitHub Actions اجرا می‌شود.

## فعال‌سازی اولیه

1. در شاخهٔ حاوی کد، Codespace با پیکربندی **Sarmo SnappPay manual login** و کوچک‌ترین ماشین موجود بساز. در فهرست **Ports** مطمئن شو دسترسی 6080 برابر **Private** است. فقط همان پورت باید منتقل شود.
2. در ابزارهای WordPress مهران، نام دقیق Codespace خودت را در پنل پایش ذخیره کن. افزونهٔ لازم نسخهٔ ۰٫۹٫۰ است. تنظیم نام، حالت ورود دستی را برای جمع‌آورنده فعال و مسیر درخواست پیامک ربات را غیرفعال می‌کند.
3. پس از آماده‌شدن محیط، با حساب مدیر وردپرس دکمهٔ **باز کردن مرورگر ورود** را بزن و در خود اسنپ‌پی وارد شو. لینک مخصوص همان تلاش است و تا ۱۲ دقیقه اعتبار دارد. اگر اسنپ‌پی در این محیط ۴۲۹ نشان داد، تست را همان‌جا متوقف کن.
4. بعد از پیام پذیرش نشست، اجرای دستی **Sarmo SnappPay rank collector** را از شاخهٔ سازگار اجرا کن یا منتظر اجرای زمان‌بندی‌شده بمان. برای پذیرش تست، در خروجی Actions تعداد مشاهدات معتبر و در وردپرس نتیجهٔ «عبا» را ببین. پذیرش نشست توسط وردپرس به‌تنهایی اثبات اعتبار آن در Actions نیست.
5. برای حفظ سهمیهٔ رایگان، پس از انتقال نشست، از فهرست GitHub Codespaces روی **Stop codespace** بزن. برای تجدید نشست، بله لینک شروع Codespace و پنل ورود وردپرس را می‌فرستد.

نشست فقط کوکی‌ها و فضای ذخیره‌سازی دامنه‌های اسنپ‌پی را شامل می‌شود. از کپی‌کردن نشست به مخزن، لاگ، چت یا Artifacts خودداری کن. اگر Codespace متوقف باشد، آن را پیش از بازکردن لینک ورود از صفحهٔ GitHub شروع کن.
